# Mana Wynwood links

GitHub Pages site for https://links.manawynwood.com.

- `/mwcc` is the Mana Wynwood Convention Center link tree from https://github.com/mana-vlad/mwcc-links
- `/mw320` is the MW320 link tree from https://github.com/mana-vlad/mw320-links

Manifest icon paths are prefixed with each base path so those icons load from the folder they live in.
